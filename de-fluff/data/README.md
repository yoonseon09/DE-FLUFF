# Data

The dataset files are not included in this repository. You can obtain them from the [dataset page](https://traversxlee.notion.site/Dataset-3756f7728b7f8022b7aafe389b285875) or generate them by running [`01_hypothesis_and_dpo_data.ipynb`](../notebooks/01_hypothesis_and_dpo_data.ipynb).

## Files

| File | Generated by | Contents |
| --- | --- | --- |
| `experiment_standard_results.json` and `experiment_minority_results.json` | Notebook 01, Section 1 | Responses by persona, three compressed versions, token counts, and Fluff Index values |
| `merged_scenarios_final.json` | Notebook 01, Section 2 | Merged experiment results with `prompt_number` identifiers |
| `dpo_fluff_api_generated_prompt_{start}_{end}.jsonl` | Notebook 01, Section 3-2 | DPO preference pairs and associated metadata for a specified prompt range |
| `final_dpo_dataset.jsonl` | Notebook 02, Section 1 | Training-ready preference pairs containing `prompt`, `chosen`, and `rejected` |
| `final_dpo_dataset_full.jsonl` | Notebook 02, Section 1 | Preference pairs with additional metadata, including atomic actions, coverage checks, and fluff scores |

## Format of `final_dpo_dataset.jsonl`

Each line contains one JSON object with the following structure:

```json
{
  "prompt": "I am an elderly senior citizen over 65 years old with very low digital literacy. ...",
  "chosen": "A concise response focused on essential actions.",
  "rejected": "The original response containing more conversational padding and repetition."
}
```

The `prompt` field contains the unformatted prompt. Notebook 02 applies the Qwen chat template before training.
